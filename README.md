# # 🎉 덕성여자대학교 ‘찬란’ 축제 웹사이트

<br>

![ver PC_1440x844](https://github.com/user-attachments/assets/6591f049-c285-4359-b11b-81cb1af33c09)


> 덕성여자대학교 2024년 축제 **‘찬란’의 공식 웹사이트**입니다.  
축제 기간 동안 학우들의 편리한 정보 접근을 위해 제작되었습니다.


<br>


## 📅 프로젝트 개요

- **진행 기간**: 2023년 5월 1일 ~ 2023년 5월 25일
- **참여 인원**: 총 13명 (기획 1명, 디자인 1명, 프론트 7명, 백 4명)
- **담당 파트**: 축제 후기 작성 페이지

<br>

## 🔎 주요 기능

### 🕒 타임테이블
- 시간대별 부스 및 행사 정보를 확인할 수 있는 타임라인

### 🗺 지도
- 부스 및 행사 위치 확인 가능

### 📢 학생회 공지
- 축제 운영 관련 공지사항 게시

### 📝 축제 후기 작성
- 학우들이 축제 후기를 자유롭게 작성

### 📷 인생네컷 프레임
- 사진을 꾸밀 수 있는 축제 프레임 제공
  


<br>

## 🗂 프로젝트 구조

```
📁 src/
└── main/
    ├── java/com/example/project/
    │   ├── config/        # 전역 설정 클래스
    │   ├── controller/    # API 요청 처리
    │   ├── dto/           # 요청/응답 데이터 구조 정의
    │   ├── entity/        # JPA Entity 클래스
    │   ├── repository/    # 데이터 접근 계층
    │   ├── service/       # 비즈니스 로직 처리
    │   └── ProjectApplication.java  # 스프링부트 실행
```
